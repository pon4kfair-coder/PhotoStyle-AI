# PhotoStyle AI

Бесплатный мобильный фоторедактор для iPhone (Safari, установка на главный экран) и других современных браузеров.

## Версия 2.1

- 16 локальных цветовых эффектов и собственные стили.
- Предпросмотр «До / После», история «Отменить / Повторить».
- Экспорт 4K (изменение размера без восстановления потерянных деталей).
- Enhance Beta — обычный локальный алгоритм повышения резкости, **не** нейросеть.
- **AI-портрет** — первая настоящая функция машинного обучения: нейросеть MediaPipe Selfie Segmenter распознаёт человека, чтобы размыть фон. Работает с портретами людей и не генерирует новые объекты.

## Как включить AI-портрет

1. Откройте `https://pon4kfair-coder.github.io/PhotoStyle-AI/` в Safari.
2. Загрузите фото человека.
3. Перейдите на вкладку **AI** и нажмите «Включить AI-портрет».
4. Первый запуск требует интернета для скачивания модели и библиотеки. Дождитесь обработки.
5. Сравните через «До / После» и сохраните фото.

Внутри функции используется `@mediapipe/tasks-vision@1.2.2` (Apache-2.0) и модель Selfie Segmenter (Google MediaPipe). Код библиотеки загружается по необходимости из CDN; сама обработка изображения происходит **на устройстве**, без отправки фото для вывода модели. MediaPipe может передавать Google диагностические и производительные метрики; при публикации приложения следует учитывать их политику конфиденциальности. Подробнее: https://www.npmjs.com/package/@mediapipe/tasks-vision

AI-портрет экспериментальный: на некоторых устройствах или при недоступности сети модель может не запуститься. Результаты зависят от сюжета фотографии, а волосы/сложный фон могут отделяться неточно. Обычные стили при этом продолжают работать.

Проект распространяется бесплатно; созданные владельцем исходные файлы редактора не следует путать с отдельно лицензируемой ML-библиотекой и моделью.

## Устранение ошибок AI-портрета

Если нейросеть не запускается во встроенном браузере, откройте приложение в Safari. Версия 2.1 пробует резервный официальный движок MediaPipe Selfie Segmentation и показывает технические детали ошибки прямо на вкладке AI. Для обоих движков нужен интернет при первой загрузке. Скорость и совместимость зависят от браузера и устройства.
